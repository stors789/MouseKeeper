## 1. 结论摘要

MouseKeeper 应采用 **“科研记录台 / Specimen Ledger”** 的视觉方向：像一件可靠、安静、精确的实验工具，而不是营销型 SaaS 或通用后台模板。界面的基本组织单位应是“字段、记录行、分区与时间线”，不是层层嵌套的圆角卡片。

推荐的核心方案是：

- 浅色使用偏冷的瓷白背景、白色工作面、石墨色文字；深色使用低蓝度墨黑背景，避免纯黑。
- 只保留六个命名色族：**Porcelain、Graphite、Assay Teal、Protocol Indigo、Signal Amber、Critical Carmine**。
- 主强调色为低饱和 **Assay Teal**；信息、实验流程使用 Indigo；警告使用 Amber；危险与不可逆操作使用 Carmine。
- 桌面端采用 240 px 侧栏 + 56 px 顶栏；中等宽度收为 72 px 图标栏；小于 768 px 使用顶栏、五项底部导航和上下文固定操作区。
- 桌面列表使用真正的数据表格；移动端重排为记录卡片，绝不把桌面表格等比缩小。
- 详情页采用“身份头 + 摘要字段带 + 主记录区 + 右侧上下文区”；移动端重组为四个信息域，而不是横向滚动的桌面布局。
- 表单默认是单页分组、渐进披露；只有 CSV 恢复、批量创建后代等不可逆或跨阶段流程使用步骤器。
- 所有数据安全反馈必须留在上下文内：写入失败时保留用户输入，危险操作显示影响范围，恢复备份先验证再确认。

### 可解释的独特设计选择：Assay Rail（测定基准线）

MouseKeeper 的签名视觉元素是一条 **2 px 的“Assay Rail”竖向基准线**，配合 6 px 方形刻度：

- 用在当前导航项左缘、记录详情的身份区、时间线和需要注意的工作队列。
- 基准线承担“当前位置 / 记录连续性 / 状态级别”的真实信息功能，不是装饰。
- 默认是 Graphite 边界色；当前焦点或主要身份使用 Teal；警告和危险才切换 Amber/Carmine。
- 线旁必须同时存在文本、图标或数字，不能只靠颜色传义。
- 不用于每张卡片，也不形成霓虹灯带；一个视觉区域最多出现一条主 Rail。

这个选择借鉴实验记录本的装订边和仪器刻度，能在高密度页面里建立纵向阅读秩序，又不会落入卡通小鼠、玻璃拟态或蓝紫渐变的套路。

**建议：** 应用壳实现后，严格按第 16 节截图矩阵和第 17 节检查清单做首次运行态审查；实施后审查应追加到本文件，不能覆盖本阶段结论。

### UI-002 — 宽功能面极易退化成廉价后台模板（高）

**证据：** 仪表盘要求大量指标（需求第 138–160 行），同时明确禁止卡片泛滥、图表堆砌、巨型圆角和 hero（第 623–638 行）。

**风险复现方式：** 若实现稿把每个指标做成独立圆角阴影卡，并在首屏放 4 个以上等权图表，即命中此风险。

**建议：** 指标放入一条“群体读数带”，注意事项使用单一工作队列；图表只保留能回答明确问题的 2–3 个。页面结构依靠栅格、分隔线和留白，不靠容器套容器。

### UI-003 — 桌面高密度与移动主流程存在结构冲突（高）

**证据：** 小鼠档案字段多、列表要求表格和紧凑视图（第 164–240 行）；同时要求移动端卡片列表和单手操作（第 650–653、687–703 行）。

**风险复现方式：** 在 390 × 844 视口打开小鼠列表；若出现整页横向滚动、6 列以上压缩文字或只剩图标操作，则失败。

**建议：** 桌面表格和移动记录卡使用同一数据模型、不同排版组件；移动端只显示决策所需字段，并通过详情进入完整信息。不得依靠 CSS 缩放表格。

### UI-004 — 数据安全反馈若只用 Toast 会掩盖失败（高）

**证据：** 需求要求处理 IndexedDB 写入失败、重复提交、恢复确认和导入错误行（第 500–542、583–600、705–714 行）。

**风险复现方式：** 模拟保存失败；如果表单关闭、输入丢失，或只闪过 Toast 而页面显示成功，即失败。

**建议：** Toast 只用于非阻断成功或可撤销提示。写入失败必须在表单/流程内持续显示，保留输入并提供重试；恢复、永久删除和清空数据必须显示影响数量与不可逆性。

### UI-005 — 状态数量会诱发“彩虹徽章”与颜色歧义（高）

**证据：** 小鼠至少有 8 个状态（第 192–201 行），笼位、任务、实验还各有独立状态；可访问性要求状态不只依赖颜色（第 1896–1909 行）。

**风险复现方式：** 将截图转为灰度或关闭颜色；若用户无法区分“繁育中/实验中/已死亡”等状态，即失败。

**建议：** 所有状态都使用“图标 + 本地化文本 + 低饱和底色”，颜色只表达语义族，不追求每个枚举一个颜色。第 5.7 节给出完整映射。

### UI-006 — 中英文、长编号和长备注会破坏固定尺寸布局（高）

**证据：** 需求明确要求处理长备注、极长编号和中英混排（第 719–722 行）。

**风险复现方式：** 使用 64 字符无空格 ID、40 字中文品系名、英文长单词、2,000 字备注测试 360 px 和 1024 px 视口。

**建议：** 标题和备注采用 `overflow-wrap:anywhere`；表格 ID 显示可辨识的首尾片段并提供完整值与复制操作；不使用固定字符宽度；按钮允许合理增宽，不把主要中文标签强制换成图标。

### UI-007 — 大数据量会放大布局抖动和操作丢失（高）

**证据：** 目标规模为 5,000 小鼠、1,000 笼位、50,000 事件和 20,000 体重记录（第 1722–1754 行）。

**风险复现方式：** 加载 5,000 行后排序、切密度、批选、展开操作菜单；如果行高不稳定、滚动跳位或选中状态丢失，即失败。

**建议：** 标准/紧凑表格使用明确行高；备注和多标签不在主表自动展开；虚拟化时保留稳定 key、选中集合与焦点。时间线默认分段加载，不能一次渲染 50,000 条。

### UI-008 — 导航宽度与操作优先级若不受控，会让全部按钮等权（高）

**证据：** 至少覆盖总览、小鼠、笼位、繁育、实验、事件、任务、数据和设置，并明确禁止所有按钮同等强调（第 623–638 行）。

**风险复现方式：** 任一页面首屏出现两个以上实心主按钮，或移动底栏塞入 6 个以上入口，即失败。

**建议：** 每个上下文最多一个实心主动作；次要动作使用描边/文字按钮；低频动作归入具名“更多操作”菜单。移动底栏固定五项，其他模块由“更多”进入。

### UI-009 — 外部字体或远程图标会破坏离线一致性（中）

**证据：** 产品必须可离线运行和安装为 PWA；当前尚无字体资产。

**风险复现方式：** 在离线网络条件重载；若字体回退导致布局跳动或图标丢失，即失败。

**建议：** 第一版使用系统字体栈和本地打包的 Lucide SVG；不请求 Google Fonts、CDN 图标或远程背景资产。

## 4. 视觉方向

### 4.1 设计关键词

**精确、安静、可追溯、紧凑、可信、耐久。**

视觉参照应更接近实验记录册、样本登记台和现代医疗工作站，不接近商业 BI 看板、加密货币仪表盘或消费级健康 App。

### 4.2 视觉层级

1. **身份**：耳标号/实验编号、记录类型、当前状态。
2. **异常与待办**：逾期、容量接近上限、数据错误。
3. **当前上下文动作**：新建、记录体重、转笼、保存。
4. **事实字段**：品系、基因型、笼位、年龄、关联实验。
5. **历史**：事件、状态变化、转笼、操作时间线。
6. **系统元数据**：创建/更新时间、内部 ID、schema/app 版本。

页面不应通过字号夸张制造层级。最大的常规页面标题仅 24 px；核心数字最多 30 px。

### 4.3 表面语言

- 应用背景与工作面只有一级轻微明度差。
- 区块主要靠 1 px 分隔线和 16–24 px 留白分组。
- 阴影只属于浮层、菜单、对话框和移动固定操作条。
- 大面积不使用渐变；图表允许同一色族内的离散色阶，但不使用装饰性渐变。
- 圆角用于表达可交互边界，不作为品牌本身。
- 图标统一使用 Lucide 1.75 px 线宽；常规 16/18 px，导航 20 px，空态 24 px。
- 不使用 emoji、卡通小鼠、DNA 水印、试管插画或拟物实验室背景。

### 5.6 间距、尺寸、圆角、边框、阴影与动效

**间距序列（4 px 基线）：**

```text
space-0=0, space-0.5=2, space-1=4, space-2=8, space-3=12,
space-4=16, space-5=20, space-6=24, space-8=32,
space-10=40, space-12=48, space-16=64
```

禁止在业务组件中新增 13、18、22、30 px 等随机间距。

**控件与数据密度：**

| Token | 桌面 | 移动 |
|---|---:|---:|
| 常规控件高度 | 36 px | 44 px |
| 紧凑控件高度 | 32 px | 不使用 |
| 最小触控目标 | 36 × 36 px（鼠标环境） | 44 × 44 px |
| 表头高度 | 40 px | 不适用 |
| 标准表格行高 | 44 px | 不适用 |
| 紧凑表格行高 | 36 px | 不适用 |
| 移动记录卡最小高度 | 不适用 | 104 px |
| 顶栏 | 56 px | 52 px |
| 底部导航 | 不适用 | 64 px + safe area |

**圆角：**

```text
radius-xs=4px   标签、微型控件
radius-sm=6px   输入框、按钮、表格菜单
radius-md=8px   移动记录卡、popover
radius-lg=12px  对话框、空态面板
radius-pill=999px  只用于状态 chip、筛选 chip、头像式计数
```

页面大容器不得使用超过 12 px 的圆角；不要把所有按钮做成胶囊。

**边框：** 默认 `1px solid var(--border-default)`；Assay Rail 为 2 px；高对比焦点环为 2 px + 2 px offset。

**阴影：**

```text
shadow-none: none
shadow-popover: 0 8px 24px rgb(15 25 30 / 0.12), 0 1px 3px rgb(15 25 30 / 0.10)
shadow-dialog: 0 18px 48px rgb(8 15 20 / 0.22), 0 2px 8px rgb(8 15 20 / 0.14)
shadow-sticky: 0 -4px 16px rgb(15 25 30 / 0.08)
```

普通卡片和表格不得使用阴影。

**动效：**

```text
motion-fast=120ms
motion-standard=180ms
motion-slow=240ms
ease-standard=cubic-bezier(.2, 0, 0, 1)
```

只允许用于悬停、菜单、抽屉、状态变化和轻量布局过渡；没有弹跳数字、循环脉冲或图表入场秀。`prefers-reduced-motion: reduce` 下取消位移和非必要过渡。

### 5.7 状态 Token 与枚举映射

状态组件统一结构：`16 px 图标 + 文本 + 可选计数`，高度 24 px，左右内边距 8 px。状态不是按钮时不得呈现可点击 hover。

| 对象 / 状态 | 语义 token | 图标建议 | 文字要求 |
|---|---|---|---|
| 小鼠：存活 | Positive | `Activity` | 显示“存活” |
| 小鼠：实验中 | Informative | `FlaskConical` | 显示“实验中” |
| 小鼠：繁育中 | Warning | `Dna` | 显示“繁育中” |
| 小鼠：预留 | Neutral | `Bookmark` | 显示“预留” |
| 小鼠：已转出 | Neutral | `ArrowUpRight` | 显示“已转出” |
| 小鼠：已死亡 | Critical-muted | `CircleOff` | 显示“已死亡” |
| 小鼠：已安乐死 | Critical-muted | `ShieldMinus` | 显示“已安乐死” |
| 小鼠：其他 | Neutral | `Ellipsis` | 显示“其他” |
| 笼位：容量正常 | Positive | `Gauge` | 同时显示 `n / max` |
| 笼位：接近上限 | Warning | `TriangleAlert` | 同时显示 `n / max` |
| 笼位：超容 | Critical | `OctagonAlert` | 同时显示超出数量 |
| 任务：待处理 | Informative | `Circle` | 显示截止时间 |

`Critical-muted` 是记录事实，不等同于当前系统错误；其底色应柔和，避免整页出现大面积红色。

- label 永久可见；placeholder 只给格式示例，不代替 label。

- 离开脏表单时使用应用内确认；浏览器关闭/刷新使用 `beforeunload` 的可用降级。

- 对话框最大高度 `min(760px, calc(100dvh - 32px))`；内容区滚动，标题和操作固定。
- 普通新建不用向导；批量创建后代、CSV 导入、恢复备份才使用步骤器。

## 11. 关键页面规格

### 11.1 首页仪表盘

信息顺序：

1. **群体读数带**：存活、笼位、实验中、繁育中、待处理、逾期。六项共享一个有分隔线的工作面，不做六张卡。
2. **需要关注**：逾期任务、容量警告、异常事件；这是首屏最主要工作队列。
3. **群体构成**：状态/性别的单一堆叠条或矩阵；直接标注数字。
4. **年龄/周龄分布**：一个直方图，回答“当前群体年龄结构如何”。
5. **品系与容量**：排名列表或条形图，避免饼图标签拥挤。
6. **最近活动**：紧凑时间线。

首页最多三个分析图；没有数据时不展示空坐标轴。显示“数据更新于”时间，不虚构实时在线。

### 11.2 笼位详情

- 身份头显示笼位编号、房间/区域、架位、用途、状态。
- 容量使用水平刻度条并始终显示 `当前 / 最大`；达到 80% 进入 Warning，超过 100% 进入 Critical。
- “移入小鼠/批量转笼”是上下文主动作；容量异常时动作前显示影响。
- 笼内小鼠为可筛选表格/移动卡片；性别、年龄范围、主要品系作为摘要字段带。
- 转笼历史使用带来源与目标的事件行，不能只写“已转笼”。
- 删除有小鼠的笼位时，确认框不能提供直接绕过的危险按钮；应引导先处理小鼠。

### 11.3 繁育组合详情

- 顶部以父本、母本、组合状态三个紧凑关联块呈现，不画无限谱系图。
- 性别或状态异常在对应亲本块内显示 Warning。
- 合笼、预计生产、分笼、窝记录使用有日期刻度的短流程轨，不做装饰性流程动画。
- 窝记录是主表；“从窝创建后代”是有真实数据前提的主动作。
- 移动端父母块纵向排列，仍明确 `父本 / 母本` 文本，不能只靠左右位置表达。

### 11.4 实验详情

- 标题区显示状态、起止日期、负责人和说明。
- 桌面将组别作为横向可比较区，但组数多时使用组别筛选 + 单表，不能无限横向卡片。
- 小鼠分配表明确组别、加入日期、退出状态和原因。
- 已结束实验降低主动作权重，保留历史浏览；不能显示仍可随意加组的误导按钮。
- 移动端用组别选择器切换，不把多列组别压缩。

### 11.5 快速称重

桌面使用专用录入表：

```text
选择队列/笼位 [A-03 ▾]       已录 8 / 12       [保存全部]
┌──────────┬────────┬──────────┬──────────┬────────┬────────────┐
│ 小鼠     │ 上次   │ 本次 g * │ 变化     │ 日期   │ 备注       │
├──────────┼────────┼──────────┼──────────┼────────┼────────────┤
│ MK-0241  │ 23.2 g │ [23.8  ] │ +0.6     │ 07-30  │ [        ] │
│ MK-0242  │ 20.1 g │ [      ] │ —        │ 07-30  │ [        ] │
└──────────┴────────┴──────────┴──────────┴────────┴────────────┘
```

- `Enter` 保存当前值并聚焦下一只，`Shift+Enter` 返回上一只；不劫持输入法组合键。
- 异常变化使用 Warning 并允许保存，必须要求可选备注而非强制阻断。
- 批量保存前持续显示未保存数量；写入失败时标出具体行并保留所有值。
- 移动端改为“一次一只”：显示进度、上次体重、大号数字输入、上一只/保存并下一只。不能显示缩小表格。

### 11.6 备份与恢复

页面分为两个清晰区域：

**备份：**

- 当前数据摘要：各实体数量、schemaVersion、上次成功备份时间。
- 一个明确主动作“导出完整 JSON 备份”；CSV 导出为次级分区。
- 成功后显示文件名、导出时间和包含的记录数。

**恢复：**

采用四步流程：

```text
1 选择文件 → 2 验证与预览 → 3 安全备份与确认 → 4 恢复结果
```

- 第 2 步显示 appVersion、schemaVersion、导出时间、实体数量、警告和阻断错误。
- 未通过验证不能进入确认。
- 确认区显示“将替换哪些数据”，主按钮使用 Critical，并包含明确动词“备份当前数据并恢复”。
- 永久清空或恢复不允许仅靠文件名确认；显示记录总数和后果。
- 恢复失败停留在结果页，说明当前数据是否回滚、自动安全备份位置和可重试动作。

### 11.7 CSV 导入

四步：上传 → 字段映射 → 行预览/校验 → 导入报告。

- 预览表逐行显示成功、警告、失败和原因；失败行可筛选。
- 映射控件同时显示源列样例和目标字段说明。
- “部分成功”必须在确认前写清将写入/跳过的数量。
- 结果页提供失败行 CSV 下载或复制错误详情，不能只显示“部分失败”Toast。

## 12. 空、无结果、加载、错误与成功状态

### 12.1 空状态

空态由四部分组成：24 px 线性图标、事实标题、一句解释、一个主动作。可有一个文字链接作为次要动作。无卡通插画。

区分：

- **首次空数据库**：“还没有小鼠记录” + “创建第一只小鼠” + “生成明确标记的示例数据”。
- **模块为空**：“尚无体重记录” + “记录体重”。
- **过滤无结果**：“没有符合这 3 个筛选条件的记录” + “清除筛选”；不能引导创建重复记录。
- **历史为空**：说明尚未发生相应事件，不显示空白大框。

### 12.2 加载与 Skeleton

- 首次页面加载使用与真实布局同尺寸的 Skeleton，避免内容跳动。
- 表格 Skeleton 显示 8–12 行和真实列宽；移动显示 4 张记录卡。
- 局部刷新保留已有内容并显示轻量进度，不把整页替换为 Skeleton。
- 按钮 loading 保留原宽并显示动词，如“正在保存…”。
- 超过 10 秒显示说明与重试，不无限旋转。

### 12.3 错误

| 场景 | 呈现 |
|---|---|
| 字段校验 | 字段下错误 + 顶部错误摘要 |
| 保存/写入失败 | 表单内 Critical alert；保留输入；重试与复制详情 |
| 列表查询失败 | 列表区域内错误；保留筛选；重试 |
| 关联记录缺失 | 在原位置显示“关联记录缺失”与修复/查看上下文 |
| 备份损坏 | 步骤器内阻断，不进入恢复确认 |
| PWA 离线 | 低干扰常驻提示“离线，本地数据仍可用”；不冒充错误 |
| 全局错误边界 | 提供重载应用、导出诊断信息；不得承诺数据已保存 |

错误详情默认折叠，包含可复制的非敏感技术信息；不要在用户界面暴露完整本地路径或真实数据内容。

### 12.4 Toast、Undo 与确认

- 成功 Toast：4–6 秒，可关闭；屏幕阅读器使用 `role=status`。
- 可撤销软删除、标签变化等显示 8 秒 Undo；撤销失败升级为持久 alert。
- 永久删除、恢复备份、清空真实数据不能用 Undo 替代确认。
- 确认框标题包含动作与对象，如“永久删除 12 只小鼠？”；正文列出历史保留/删除范围。
- 对话框默认焦点放安全动作；关闭后焦点回到触发元素。

## 13. 按钮、菜单与操作优先级

每个页面或对话框最多一个实心 Primary：

1. **Primary**：当前流程最主要的正向动作，如“保存小鼠”。
2. **Secondary**：描边，用于编辑、导出、预览。
3. **Tertiary**：文字/幽灵，用于取消、查看。
4. **Danger**：只用于实际破坏性动作；不能作为普通强调色。

约束：

- 按钮必须是动词 + 对象；避免只有“确定”“提交”。
- 图标单按钮必须有 accessible name 和 tooltip；主流程不使用无文字图标按钮。
- `⋯` 只容纳低频、可解释动作；菜单不能有空项或 “Coming soon”。
- 禁用按钮旁必须能知道为什么禁用；若原因重要，提供说明文本。
- 行内高频动作最多两个，避免每行出现一排同权按钮。
- 所有可见按钮都必须有实际功能；尚未实现的功能不渲染入口。

## 14. 可访问性与国际化

### 14.1 WCAG 基线

- 正文对比度至少 4.5:1；大字至少 3:1；边界、焦点和图形对象至少 3:1。
- 使用 `:focus-visible` 2 px Focus + 2 px offset；深浅主题都清晰。
- 首个可聚焦元素提供“跳到主要内容”链接。
- 导航、main、aside、表格、列表、表单使用原生语义。
- 对话框锁定焦点，`Escape` 在不丢数据时关闭，关闭后恢复焦点。
- 状态、图表、容量和错误不得只靠颜色。
- 动态保存结果使用恰当的 `aria-live`；不能反复播报每次按键。
- 字段 `label`、描述、错误通过 ID 关联；必填和非法状态可被读屏识别。
- 触控目标至少 44 × 44 px；相邻危险和安全动作至少 8 px 间距。
- 支持 200% 浏览器缩放，不丢字段、操作或产生整页双向滚动。
- 尊重 `prefers-reduced-motion` 和 `prefers-color-scheme`。

### 14.2 键盘

- `/` 聚焦全局搜索；输入框内不触发。
- `Tab` 顺序与视觉顺序一致。
- 表格使用原生链接、按钮、复选框；除非完整实现 ARIA Grid，不伪装成 spreadsheet。
- 快速称重提供可发现的 Enter 导航提示。
- 筛选 chip 可聚焦并通过 Delete/Backspace 删除，但仍有可点击关闭按钮。
- 拖拽排序若未来出现，必须有上移/下移替代操作。

### 14.3 中英文与格式

- 根节点设置正确 `lang`；语言切换后更新。
- 日期、时间、数字和单位使用 `Intl`；输入存储与显示格式分离。
- 不把中文按钮限制在按英文长度设计的固定宽度。
- 字段标签可换行一行；移动端标签与输入垂直排列。
- 64 字符无空格内容使用 `overflow-wrap:anywhere`，不能撑破容器。
- 截断内容必须有可键盘访问的完整值；不能只依赖鼠标 hover 的 `title`。
- 重量单位与数值在视觉和读屏上保持关联，例如 `23.8 g`。

## 15. 明确的反模板检查

以下任一项出现即应在 UI 审查中判为失败：

1. 首页有大面积蓝紫渐变、装饰性光晕或欢迎 hero。
2. 六个指标被做成六张同尺寸、同阴影、同强调色的卡。
3. 页面每个区块都被圆角容器包裹，出现卡片套卡片。
4. 普通内容容器圆角超过 12 px，或所有按钮都是胶囊。
5. 普通表格/面板使用明显投影；深色模式出现发光边框。
6. 图表超过三个，或图表不能回答具体群体管理问题。
7. 使用卡通小鼠、试管、DNA 螺旋作为大幅装饰。
8. 导航 Logo 使用廉价渐变图标，或者侧栏只靠图标猜含义。
9. 一个页面首屏出现两个以上同权实心按钮。
10. 用颜色区分状态但没有文字/图标。
11. 手机端出现缩小桌面表格或整页横向滚动。
12. 使用玻璃拟态、背景模糊或透明层叠作为主要风格。
13. 以动画数字、循环脉冲、无意义入场动效制造“科技感”。
14. 大量使用 “Coming soon”、TODO、假筛选、假菜单或只弹 Toast 的按钮。
15. 直接使用组件库默认的蓝色、圆角、阴影，而未映射本报告 token。
16. 用五颜六色的 chip 为每个枚举造一个颜色。
17. 用超大留白让关键列表在 900 px 高屏幕只显示 3–4 行。
18. 空态用通用插画占据半屏，却没有清晰下一步。

通过标准：即使隐藏品牌名，界面仍能通过 Assay Rail、指标读数带、低饱和六色体系和记录优先的信息结构辨认出是 MouseKeeper，而不是换 Logo 的管理后台。

## 16. 页面视觉验收标准

### 16.1 强制截图矩阵

首次实现和每轮大改后至少检查：

| 视口 | 主题 | 内容状态 |
|---|---|---|
| 1440 × 900 | 浅色、深色 | 正常数据、长文本 |
| 1024 × 768 | 浅色、深色 | 表格、详情、对话框 |
| 768 × 1024 | 浅色 | 折叠侧栏、表单 |
| 390 × 844 | 浅色、深色 | 主流程、键盘弹起后的表单 |
| 360 × 800 | 浅色 | 极长编号、中英混排 |
| 1280 × 720 @ 200% zoom | 任一 | 导航、表单、确认框 |

每组至少包含：仪表盘、小鼠列表、小鼠详情、新建/编辑、笼位详情、繁育详情、实验详情、快速称重、备份恢复和一个空/错误/加载状态。

### 16.2 全局可量化验收

- 360 px 宽度无整页横向滚动；允许明示的图表或代码局部滚动，但本项目常规页面不应需要。
- 1440 × 900 的标准密度小鼠列表首屏至少可见 12 条完整数据行。
- 390 × 844 的移动列表首屏在顶栏/筛选/底栏存在时至少可见 3 条记录的主要信息。
- 所有移动可交互目标达到 44 × 44 px。
- 常规页面标题不超过 24 px，核心数字不超过 30 px，容器圆角不超过 12 px。
- 一个上下文最多一个实心 Primary。
- 所有状态含文字；转成灰度仍可识别其含义。
- 深色主题无纯黑大底、纯白刺眼正文、低对比边界或高饱和荧光色。
- 长 ID、长品系、2,000 字备注、中英混排不覆盖相邻内容。
- 对话框高度不超过视口，标题与操作始终可达。
- 键盘焦点在所有交互控件上可见，关闭对话框后回到触发点。
- 加载 Skeleton 与最终布局结构一致，不发生明显列宽/卡片高度跳变。
- 写入失败不关闭表单、不清空输入、不显示虚假成功。
- 所有可见按钮、菜单项、筛选和链接都有真实行为。

### 16.3 逐页验收

| 页面 | 必须通过的视觉与交互条件 |
|---|---|
| 首页 | 群体读数是一个分段带，不是卡片墙；“需要关注”优先于图表；分析图 ≤3；无数据不画空图 |
| 小鼠列表 | 桌面表格列对齐、选择/排序/筛选状态明确；移动重排为卡片；批量条不遮内容 |
| 小鼠详情 | 身份、状态、笼位首屏可见；关联对象是链接；时间线可分段加载；缺失关联有明确文案 |
| 新建/编辑 | label 永久可见；移动单列；错误摘要可跳转；固定保存区不遮字段；离开脏表单会警告 |
| 笼位详情 | 容量同时显示数字与语义；接近/超容不只靠颜色；笼内小鼠和转笼历史可用 |
| 繁育详情 | 父本/母本用文字标明；异常就地提示；窝记录优先；不出现装饰性无限谱系图 |
| 实验详情 | 状态、日期、负责人清晰；组别多时不无限横向扩张；历史实验仍可读 |
| 快速称重 | 桌面连续键盘录入；移动一次一只；异常值可保存但有提示；失败行保值 |
| 备份恢复 | 备份和恢复视觉隔离；恢复有验证预览和影响数量；损坏文件不能进入确认 |
| CSV 导入 | 映射、预览、错误原因和部分成功数量清晰；结果不是只靠 Toast |
| 移动主流程 | 可在 390 px 单手完成新建小鼠、称重、转笼、改状态、添加事件、完成任务 |
| 状态页 | 首次空、过滤无结果、加载、局部错误、全局错误和离线状态彼此不混淆 |

### 16.4 内容压力测试夹具

视觉验收必须至少使用以下内容：

```text
ID: MK-2026-ABCDEFGHIJKLMNOPQRSTUVWXYZ-0123456789-EXTRA-LONG-000042
耳标: EAR-TAG-WITHOUT-BREAK-ABCDEFGHIJKLMNOPQRSTUVWXYZ
中文品系: 条件性敲除转基因杂合背景回交第十二代实验观察组
英文品系: B6.129S4-Trp53tm1Tyj/J-backcross-observation-cohort
基因型: Trp53 flox/flox; Rosa26-CreERT2 +/-; Reporter +/-
备注: 2,000 个中英混排字符，包含长 URL 形态文本但不实际联网
标签: 12 个标签，其中 3 个名称超过 20 字符
```

同时验证 0 条、1 条、50 条、5,000 条小鼠记录，以及时间线 0/20/1,000/50,000 条的分段状态。

## 17. 实施交接顺序

1. 先在全局样式中落地语义 token、系统字体、焦点环和主题切换；禁止页面自带颜色体系。
2. 实现响应式壳层、桌面/移动导航、全局搜索入口和上下文操作插槽。
3. 建立 Button、Field、StatusChip、Alert、EmptyState、Skeleton、Dialog、Toast、DataTable、MobileRecordCard 等基础契约。
4. 先用小鼠列表/详情/表单验证密度和断点，再复用到笼位、实验和任务。
5. 单独实现快速称重、备份恢复、CSV 导入流程，不把它们硬塞进通用 CRUD 对话框。
6. 在 1440、1024、390、360 px 和深浅主题下做第一次截图审查。
7. 加入长文本、空态、失败态与大数据夹具后再精修；不能只用理想短假数据验收。
