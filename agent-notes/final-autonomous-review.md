# MouseKeeper 最终自主审查报告

审查日期：2026-08-01（Asia/Shanghai）

## 1. 交付结论

MouseKeeper v0.1.0 已从空目录实现为可构建、可离线打开、无后端的本地优先 React PWA。核心业务事实写入 Dexie/IndexedDB；页面没有用假按钮、静态示例或 localStorage 冒充业务存储。当前 Chromium 自动化覆盖小鼠、笼位、繁育、实验、事件、体重、任务、JSON 恢复、CSV 和回收站的纵向闭环。

最终仲裁没有保留已知阻断级问题。交付仍不是受监管 LIMS，也没有把未实测的浏览器重启、Safari/Firefox/真机、屏幕阅读器或大文件峰值声称为通过。

## 2. 实际实现

- 总览：存活/实验/繁育/任务指标，性别、品系、状态和周龄分布，最近小鼠/活动、容量和异常关注项。
- 小鼠：建档、编辑、复制、批量建档、搜索/筛选/排序/分页、保存视图、批量状态/转笼/标签、谱系、详情时间线、软删除/恢复/永久删除保护。
- 笼位：容量和组成、成员、移入/移出/转笼历史、48 条分页、可配置展示预警、占用状态保护。
- 繁育：组合、状态、父母/日期规则、窝、断奶字段和整窝后代单事务。
- 实验：实验与初始组、互斥组、批量加入/退出、活动成员终结保护和跨模块历史。
- 记录：一般事件、声明时区、体重/事件一对一、趋势、快速称重批次、编辑/软删除/恢复。
- 任务：创建/编辑、今日/逾期/未来、关联筛选、完成/恢复/取消/回收。
- 数据：16 表 JSON 信封、SHA-256、严格预检、精确恢复前副本、全表替换回滚、CSV 逐行导入/五类活动数据导出、公式中和、示例批次与完整性扫描。
- 客户端：浅/深/系统主题、桌面侧栏、Pixel 7 布局、全局搜索焦点、未保存导航保护、路由拆包、manifest、静态白名单 Service Worker。

## 3. 架构裁决

保留单体前端和明确分层：domain 负责 schema/纯规则，db 负责 Dexie 和扫描，services 负责所有业务写入，features 负责交互，backup/import-export 复用同一信任边界。没有引入后端、云数据库、账号、多租户或重量级状态设施。

关键数据策略：

- 16 张表 schemaVersion 1；所有实体有 revision、软删除、来源和时间字段。
- 活动唯一 helper key 交给 IndexedDB 唯一索引；外键/状态/谱系规则由服务事务和扫描双重检查。
- operationId 与请求指纹防重放误用，expectedRevision 防旧页面覆盖。
- Mouse.currentCageId 等投影可加速读取，但权威事实仍是历史关系表；scanner 检查漂移。
- 普通备份必须通过恢复级验证；精确恢复前 salvage 副本忠实保存旧状态，不因旧库已经不一致而阻止有效恢复。

## 6. 停止条件审查

已满足：lint、TypeScript、67 个 Vitest、coverage 命令、生产构建、默认核心 E2E、控制台错误检查、IndexedDB 刷新保留、JSON 导出/恢复/损坏拒绝、CSV 预览/隔离/导出、全部核心业务闭环、Pixel 7 主要流程、浅/深色、README、6 轮审查和清晰原子 Git 历史。

未能真实验证的停止条件只有“关闭浏览器进程后重启仍保留”及跨平台/真实设备扩展矩阵。原因不是代码依赖后端，而是当前 Playwright fixture 没有持久 browser profile 的跨进程发布测试；替代证据是同 context reload、Dexie schema、无清库启动路径和 IndexedDB 持久事实。该项在测试报告与 known limitations 中明确标为未验证，没有冒充通过。

## 7. 残余风险

1. 数据只在浏览器明文 IndexedDB；下载 JSON/CSV 也明文。设备/profile/文件保护由用户负责。
2. DataPage、小鼠复杂筛选、完整性扫描和备份仍可能全量物化；100 MiB 边界在低内存设备存在峰值风险。
3. 浏览器和辅助技术矩阵有限；Chromium 通过不能外推 Safari、Firefox、Edge、VoiceOver/NVDA 或真机。
4. 当前只有 schemaVersion 1，迁移纪律有文档但没有 v1→v2 真实 fixture。
5. 实验重新开放、任务恢复关联的最终产品语义仍待真实使用反馈。

## 8. 最值得继续的三个方向

1. 建立持久 browser profile 的跨进程重启、PWA 升级、多标签 `blocked/versionchange` 和 Firefox/WebKit/Edge/真机发布矩阵。
2. 将小鼠/DataPage 查询下推 IndexedDB 游标分页，并为备份/CSV 引入 Worker、可观察进度和 25/50/100 MiB 内存基准。
3. 用真实实验流程决定实验 reopen 与任务恢复关联策略，形成状态迁移 ADR 和对应服务/E2E，而不是直接增加更多功能。
