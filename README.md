# MouseKeeper

MouseKeeper is a local-first mouse colony manager for individual researchers.
The application stores research records in the browser with IndexedDB and does
not require an account or server.

## Development

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

The full usage, backup, import, PWA, and architecture guides will be completed
alongside the implemented workflows.
