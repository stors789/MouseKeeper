# 已知限制

以下是 MouseKeeper v0.1.0 的明确边界，不应被理解为已实现功能。

## 平台与部署

- 自动 E2E 只运行 Playwright Desktop Chromium 和 Pixel 7 Chromium 模拟。未完成 Firefox、Safari/WebKit、Windows Edge、真实 Android/iOS 设备的完整矩阵。
- 离线自动化证明已受 Service Worker 控制的生产应用能打开未访问过的工作区；尚未自动验证浏览器进程重启、操作系统重启、多标签页升级阻塞和长期离线更新。
- PWA 安装入口、持久存储授权和下载行为由浏览器/部署来源决定；HTTP 非 localhost 部署通常不能安装 Service Worker。

## 数据安全

- 没有云同步、服务器副本或自动远程备份。清除站点数据会删除 IndexedDB。
- JSON 备份未加密、未签名；SHA-256 只检测意外变化。敏感备份需要用户自行加密和控制访问。
- 当前 schemaVersion 为 1，只定义了未来迁移纪律，没有可供实测的旧版本升级路径。
- 不提供跨备份合并；恢复总是验证后替换全部本地数据。
- 浏览器存储配额、磁盘耗尽和真实 100 MB 备份尚未在全部平台故障注入。

## 产品范围

- 单用户、单设备本地模式；没有登录、权限、多租户、协作、审计签名或法规认证。
- 没有云提醒、系统级定时后台任务或推送；任务提醒只存在于应用界面。
- 没有复杂统计、实验结果分析、无限代谱系图、二维码/RFID、库存、采购或第三方 LIMS 集成。
- CSV 只支持导入小鼠；笼位、实验、体重和事件提供导出，但没有对应 CSV 导入。
- 恢复软删除小鼠不会自动重开删除时关闭的笼位、实验或繁育关系，以避免伪造历史。
- 已取消/归档且没有活动成员的实验可通过编辑重新设为计划中/进行中；当前没有要求原因的独立“重新开放”命令。
- 恢复任务会保留原关联 ID，即使关联小鼠、笼位或实验仍在回收站；关系未悬空，但列表可能把关联对象显示为不可用，当前没有一键解除关联流程。

## 性能与规模

- 小鼠和笼位列表使用分页，事件/体重/活动中心最多显示最近或筛选后的 100 条；分页控制 DOM，但部分查询仍会先读取全量候选及关系表，不是 IndexedDB 游标分页或完整虚拟化。
- 数据模型与索引面向 5,000 小鼠、1,000 笼位、50,000 事件和 20,000 体重设计；当前交付未把这组最大规模在多台真实设备上做可重复 p95/内存基准，因此不能给出统一延迟保证。
- 仪表盘、全局搜索、完整性扫描、JSON 导出/恢复仍有必须线性扫描全部相关记录的操作，大库下会占用主线程和内存。
- CSV 导入在批次开始时建立父母、笼位和标签映射，但仍为每个合法行使用独立事务；超大批次的事务调度、字符串和预览内存仍随行数增长，20 MB 上限用于避免无界输入。

## 兼容与可访问性

- 中文为主要界面语言，数据字段支持中英文混排，但没有完整国际化框架。
- 自动测试覆盖语义标签、焦点深链、未保存导航、深色与横向溢出；尚未通过独立屏幕阅读器、语音控制或完整 WCAG 2.2 人工审计。
- 体重异常是启发式提示，不是医学或实验判断，不会阻止保存。

值得优先扩展的方向见最终交付报告；新增功能前仍应优先完善真实平台、备份演练和规模基准。
