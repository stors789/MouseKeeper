# Agent 隐私与本地存储

MouseKeeper 的 16 张业务表继续保存在 `MouseKeeper` IndexedDB。Agent 命令历史、工具轨迹、逐行恢复差分和必要的完整恢复快照保存在独立的 `mousekeeper-agent` IndexedDB；这使普通业务备份保持原有格式，也避免秘密配置混入业务数据。终态命令按条数自动保留最多 200 条，运行中记录不会因裁剪丢失。

发送到配置模型的内容包括用户自然语言、当前路由/选中对象、时间与时区、按需查询结果、能力参数和工具执行结果。查询结果可能包含实验业务数据，因此使用远程 Provider 就意味着这些被调用的数据会发送到该 Provider。需要完全本地处理时，请使用受信任的本地兼容模型服务。

不会发送：API Key 原文、秘密请求头、浏览器存储转储、未被工具查询的整个数据库、恢复快照。错误、命令提示和日志会对常见 Key/Authorization 形式做脱敏，但脱敏不能替代避免把秘密输入命令框。

清除浏览器站点数据会同时删除业务数据库、Agent 历史、Provider 配置和浏览器保存的 Key。普通 JSON 备份不包含 Agent 历史或 LLM 配置；非秘密 LLM 配置必须从设置页单独导出。Agent 历史当前没有云同步或加密，设备层保密依赖操作系统磁盘加密和浏览器配置保护。
